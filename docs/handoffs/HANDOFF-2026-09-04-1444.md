## Key decisions
- **Working model**: lead does a Phase 0 foundation commit on main (shared fields, stubs, contract doc with a one-owner-per-path table), then Workflow-tool agents do read-only triage in worktrees with a skeptic pass, the lead reviews and writes binding decisions into the contract doc, then implementation agents run in per-agent worktrees on branches, gate before handback, and the lead merges. `src/engine/Engine.ts` is lead-only; agents return patch descriptions.
- **Subagents run on Sonnet** (`model: 'sonnet'` on every `agent()`); the first Fable-model triage hit the monthly spend limit. Saved as a memory too.
- **Economy**: value-potential test (`src/tests/economy.test.ts`) is the guard; 11 recipes removed incl. the three tool-free stone sources so the pickaxe progression can't be skipped; crystal (objective block) can neither be crafted nor placed.
- **Tool tiers**: `requiresTool` is the type gate, `minTier` the level gate; under-tier breaks drop nothing and are slower; no extra durability cost; creative ungated.
- **Invisible wall** was `unloadColumn` never re-meshing surviving neighbours, not mesh culling. Island worlds get a visible STONE ring y=1..SEA_LEVEL+6.
- **Existing saves**: no per-world gen-version flag. Unmodified chunks regenerate under the new biome split, tree clustering and species; modified chunks keep stored data (seams possible). Island/demo worlds only gain the border ring and species.
- **Inventory**: `craftInput` regions are never quick-move destinations; leftovers on close are parked, not dropped; one craft per shift-click on an output slot.
- **Wood variants**: ids 50–55 append-only; oak 5/6/11 permanent; recipes stay numeric id grids where a wood cell means "any species of that part", result follows a single-species input, mixed → oak; fuel derived from `burnable`; PlayerModel held-block colours dropped as unreachable; minimap keeps a separate Leaves colour.
- Tooling: `.claude/` (agent worktrees) is excluded in `tsconfig.json`, `eslint.config.mjs` and `.gitignore` — otherwise agent branches break main's gate.
